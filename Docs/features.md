# Features — Entrega 1

| Id | Feature | Alcance | Tramo |
|---|---|---|---|
| F-001 | Lienzo infinito | Canvas a resolución física, cámara (desplazamiento + zoom), dibujo por capas | S2 |
| F-002 | Pluma y lápiz | Trazo con perfect-freehand; presión real con lápiz digital, simulada con mouse | S2, S3 |
| F-003 | Pizarras locales | Lista, crear, abrir, renombrar, borrar, miniatura, autoguardado | S2, S3 |
| F-004 | Goma | Borra trazos/elementos completos que toca | S3 |
| F-005 | Barra de herramientas | Flotante, arrastrable, orientación horizontal/vertical, posición recordada | S3 |
| F-006 | Historial | Deshacer/rehacer de toda operación sobre la escena | S4 |
| F-007 | Selección | Clic, Shift+clic, rectángulo, Ctrl+A, mover, borrar, cambiar color/grosor | S4 |
| F-008 | Navegación | Mano, espacio, botón medio, rueda, pinza, controles y atajos de zoom | S5 |
| F-009 | Fondos | Cuadriculado, rayado, puntos, liso; por pizarra | S5 |
| F-010 | Configuración | Tema, rueda (zoom o desplazar), dedo (dibujar o navegar), fondo por defecto | S5 |
| F-011 | Exportar | PNG (2x) y SVG, de todo o de la selección | S5 |
| F-012 | Formas | Rectángulo, elipse, línea, flecha (Shift = proporción/ángulo fijo) | S6 |
| F-013 | Texto | Crear con clic, editar con doble clic, multilínea | S6 |
| F-014 | Resaltador | Trazo translúcido de ancho fijo, siempre debajo de la tinta; negro se vuelve amarillo | S7 |
| F-015 | Portapapeles | Copiar, cortar, pegar (en el puntero, entre pizarras) y duplicar | S7 |
| F-016 | Transformar | Manijas para redimensionar (Shift = proporción) y rotar (Shift = pasos de 15°) | S8 |
| F-017 | Ahorro de memoria | Opción que arranca sin GPU (~101 MB vs ~179 MB); se aplica al reiniciar | S9 |
| F-018 | Imágenes | Pegar o arrastrar; se guardan aparte, achicadas a 2048 px | S10 |
| F-019 | Exportar PDF | PDF vectorial de una página, con o sin fondo, todo o selección | S10 |

## Atajos
| Tecla | Acción |
|---|---|
| V | Seleccionar |
| H | Mano |
| P | Pluma |
| B | Lápiz |
| M | Resaltador |
| E | Goma |
| R / O / L / A | Rectángulo / Elipse / Línea / Flecha |
| T | Texto |
| Espacio (mantener) | Mano temporal |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | Deshacer / Rehacer |
| Supr / Backspace | Borrar selección |
| Ctrl+A | Seleccionar todo |
| Ctrl+C / Ctrl+X / Ctrl+V | Copiar / Cortar / Pegar (también imágenes) |
| Ctrl+D | Duplicar |
| Ctrl + / Ctrl - / Ctrl 0 | Acercar / Alejar / 100% |
| Shift+1 | Encuadrar todo |
| Ctrl+N | Nueva pizarra |
| Esc | Soltar selección / volver a seleccionar |
